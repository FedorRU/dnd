# Гримуар партии

Офлайн-помощник по заклинаниям D&D 5e (2014) для телефона. Все 9 классов, выбор заклинаний по уровню, ячейки, концентрация, отдых, очки чародейства, договор колдуна. Тексты заклинаний в приложение не встроены: каждый один раз импортирует файл `dndsu_spells.json`.

## 1. Выложить на GitHub Pages (один раз, ~5 минут)

1. На github.com нажмите **New repository**, имя например `grimoire`, тип **Public**, создайте.
2. На странице репозитория: **Add file → Upload files**, перетащите всё содержимое этой папки (`index.html`, `app.js`, `sw.js`, `manifest.webmanifest`, папку `icons`). Нажмите **Commit changes**.
3. **Settings → Pages**: в «Build and deployment» выберите *Deploy from a branch*, ветка `main`, папка `/ (root)`, **Save**.
4. Через минуту появится адрес вида `https://ВАШ_ЛОГИН.github.io/grimoire/`.

Файл `dndsu_spells.json` в репозиторий **не кладите**: репозиторий публичный.

## 2. Поставить на айфон

1. Откройте адрес в **Safari** (именно Safari).
2. «Поделиться» → **«На экран Домой»** → «Добавить».
3. Запустите с иконки, нажмите «Выбрать файл» и выберите `dndsu_spells.json` (из «Файлов», Telegram и т. п.).

Дальше приложение работает без интернета. Персонажей можно сохранять в файл и загружать обратно (вкладка «Персонаж»).

## 3. Обновления

Поменяли файлы — загрузите их в репозиторий заново и увеличьте `VERSION` в `sw.js` (например `grimoire-v2`). Телефоны подхватят новую версию при следующем запуске с интернетом.

## Проверить на маке без GitHub

```
cd папка_приложения
python3 -m http.server 8000
```
и открыть http://localhost:8000

## Raspberry Pi

Тот же сайт открывается в Chromium в режиме киоска:
`chromium-browser --kiosk https://ВАШ_ЛОГИН.github.io/grimoire/`
Формат файла заклинаний и файла персонажа общий, его можно читать и из своей программы на Python.
